## 🔧 Tuning-System (调律)

Das Aufwertungssystem in Where Winds Meet heißt **调律 (Tiáo Lǜ)** und hat mehrere Untersysteme:

### Basis-Upgrades
| Mechanik | Funktion |
|----------|---------|
| **调律 (Tuning)** | Basis-Upgrade: Ausrüstung leveln mit XP-Material (狗粮 – Dog Food) |
| **变音 (Variable Tune)** | Ändert einen Substats (kostenpflichtig – Reroll) |
| **转律 (Transfer Law)** | Transferiert Upgrade-Level von Item A → Item B |
| **承音 (Inherit Tune)** | Überträgt Substats von Item A → Item B (konsumiert A) |
| **传律 (Pass Law)** | Überträgt Set-Boni zwischen Items → **erlaubt gemischte Sets!** |

### Fortgeschritten
| Mechanik | Funktion |
|----------|---------|
| **定音 (Fixed Tune)** | Fixiert einen Substats auf max. Wert |
| **叠音 (Stack Tune)** | Verbessert Affix-Qualität: Grün → Blau → Lila → Gold |
| **武库 (Armory)** | Aufbewahrung: Slots für verschiedene Builds |

### Seltenheitsstufen
`Grün → Blau → Lila → Gold → 🔴 Legendär`

## 💊 Verbrauchsgüter für Bosskämpfe

Vor jedem schweren Bosskampf solltest du dich eindecken:

| Item | Effekt | Einsatz |
|------|--------|:-------:|
| **Angriffs-Trank** | +X% Angriffskraft (30s) | ⭐⭐⭐ Jeder Boss |
| **Elementar-Elixier** | +X% Elementarschaden (30s) | ⭐⭐ Burst/Magic-Builds |
| **Verteidigungs-Elixier** | +X% DEF + Schadensreduktion (30s) | ⭐⭐⭐ Tank/Erstversuche |
| **Ausdauer-Trank** | Ausdauer-Regeneration über Zeit (20s) | ⭐⭐ Sustain/Mobility |
| **Heilungs-Pille** | Große Heilung + HoT (10s) | ⭐⭐⭐⭐ Pflicht! |
| **Stagger-Öl** | +X% Stagger-Aufbau (15s) | ⭐⭐⭐ Stagger-Builds |

**Empfohlene Boss-Kombination:**
> **2× Angriffs-Trank + 1× Elementar-Elixier + 1× Ausdauer-Trank + 3× Heilungs-Pillen**
