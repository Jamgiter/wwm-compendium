# WWM Compendium 🏯

**Where Winds Meet** – Deutsches Fan-Wiki mit Waffen-Guides, Boss-Strategien und Build-Optimierung für das Open-World Wuxia-RPG von NetEase.

## Technologie

Gebaut mit [VitePress](https://vitepress.dev/) – statische Markdown-Seiten, schnell und kostenlos hostbar.

## Lokal entwickeln

```bash
npm install
npm run dev    # Dev-Server auf http://localhost:5173
npm run build  # Produktions-Build
```

## Deployment

Die Seite wird automatisch per **GitHub Actions** auf **GitHub Pages** deployed.
Einfach das Repo auf GitHub erstellen und auf `main` pushen.
